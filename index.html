In productionMyHotelAuditor fulfillment platform

An agent pipeline that researches, writes and scores a hotel audit, then waits for a human.

A paid order on the website starts a run. The platform fans out one workflow per report, gathers evidence from the property's own site, official APIs and search, has models analyze it under strict rules, and holds every report for my approval before the buyer sees it.

  • Durable, queue-driven workflows on Cloudflare run reports in parallel, with retry and re-collect from a QA console.
  • Every AI finding is checked against stored, dated evidence. If it can't be traced, it doesn't ship. Scores are computed by code, not by a model.
  • The console holds the prompt library, a per-report model map, cost estimates per run, and lane policies such as cost ceilings.
  • A daily scheduled job handles data retention; a 60-minute hold gives each buyer a window to change or cancel.

Pipeline, per report

  1. OrderSigned webhook from Stripe creates the run
  2. HoldScheduled 60-minute window to change or cancel
  3. CaptureOwn site, official APIs, search, with a 24-hour cache
  4. ExtractOne model call per stored page, fidelity-checked
  5. AnalyzePinned prompt; findings validated against evidence
  6. ScoreDeterministic rubric in code
  7. RenderHTML and PDF report version
  8. ApproveHuman QA, then delivery by secure link

Approach

How I take a page from request to result.

The same four steps run every project above, whether the request comes from product marketing, recruiting or the communications team.

  1. Name the audience and the action

    Who is this page for, what do they already know, and what should they do next? One page, one primary action.

  2. Structure the journey

    Navigation, page flow and content hierarchy, drafted as an outline and a quick AI-assisted prototype before design time is spent.

  3. Build and QA with partners

    Produce in the CMS or brief the agency with a clear spec. Check copy, links, accessibility, performance and tracking before anything publishes.

  4. Measure and improve

    GA4 and GTM events on the actions that matter, A/B tests where traffic allows, and a regular review of where people drop off.
